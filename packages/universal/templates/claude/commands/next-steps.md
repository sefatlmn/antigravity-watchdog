description: Synthesize and execute forward-looking Next Steps plans adhering to /plan standard
---

Use the Next Steps tools to plan and execute milestones:
1. Call `qa_watchdog_next_steps` to synthesize 4 project-grounded implementation plans.
2. Call `qa_watchdog_execute_plan` with the plan ID (1, 2, 3, or 4) to load the plan prompt.
3. Call `qa_watchdog_goal` to inspect or update the repository milestone goal.
